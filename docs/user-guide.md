# 用户使用说明（UI / UX）

> 适用对象：Wonslate（万邦译）桌面版使用者。界面为 .NET 10 WPF，翻译核心为 Rust `translator_engine`。
> 版本口径：以界面顶部显示的「Rust 引擎版本」为准（本文撰写时为 `0.1.0`）。
> 缩写（TM、FFI、ASR 等）解释见 [terminology.md](terminology.md)；程序化集成见 [sdk.md](sdk.md)。

## 1. 安装与启动

**构建并启动（Windows）**

```bash
python script/build.py --run
```

依赖：Rust 1.98+、.NET SDK 10.0+（WPF 客户端仅 Windows 可构建）、Python 3（构建脚本）。
产物：`translator_engine/target/release/translator_engine.dll` 与 `Wonslate.UI/bin/Release/net10.0-windows/Wonslate.exe`。

**首次启动零下载**：内置 `demo` 引擎带一张小型中英词表，可立即跑通 `界面 → FFI → Rust` 全链路（词表实测样例见 [README.zh-CN.md](../README.zh-CN.md#快速体验demo-引擎)）。

**模型按需准备**（不装不影响启动，只影响语言覆盖与质量）：

| 目标 | 准备命令 | 体积 |
|---|---|---|
| en↔zh 实时离线翻译 | `python script/fetch_argos_models.py` | 每对约 85 MB |
| 11 种语言任意互译（离线主力） | `python script/fetch_madlad_model.py` | 约 3 GB |
| 精译档 AI 升级 | 本机运行 Ollama 并 `ollama pull qwen3:8b` | 5.2 GB |
| 语音识别与合成 | `python script/fetch_voice_models.py --only all` | 约 1 GB |

硬件门槛与更多配置入口见 [hardware-requirements.md](hardware-requirements.md)。

### 1.1 离线整合包（内网／涉密机器，装它不需要联网）

上面四条准备命令都假设“装它的那台机器能出网”。对禁止联网下载的客群，改走**离线整合包**：一台能出网（或已装好模型）的机器把应用与模型一起打成一个交付包，目标机器只拷贝这个包即可，全程不拨出公网。

**在一台 Windows 开发／打包机上产出**（可选先把应用发成单文件）：

```bash
# 1) 可选：把 WPF 应用发成 self-contained 单文件（需 .NET SDK，产物只在本机，不入库）
python script/pack_installer.py publish --app Wonslate.UI/bin/Release/net10.0-windows --pub <发布目录>
# 2) 把已装好的模型资产打成一个离线包
python script/offline_bundle.py pack --src <数据目录>/models --out models.zip
# 3) 把应用与模型一起装进一个交付包
python script/pack_installer.py assemble --app <要发的应用目录> --models models.zip --out wonslate-delivery.zip
```

**把 `wonslate-delivery.zip` 拷到离线机器后**：

```bash
python script/pack_installer.py verify wonslate-delivery.zip    # 先验完整性与可用性
# 验过再解压使用：app/ 里是应用；models/ 里是上面那个离线包，用
python script/offline_bundle.py install models/models.zip --dest <数据目录>/models
```

`verify` 不只是核对“字节和当初一致”——它还会把内嵌的模型包用 `offline_bundle` 那套真判据再过一遍，所以一个“哈希对得上、但内嵌包自己已经答不上是哪一版”的交付包会被当场拒绝。交付包**没有**随附可被公开信任的签名（GA-4 签名那一半需要外部证书），`verify` 靠的是内容自校验与逐文件哈希，请在受控的内部渠道转交。整合包的实现与判据详 [hardware-requirements.md](hardware-requirements.md) §7。

### 2.1 顶部信息区

- **启动诊断**（琥珀色）：Rust 引擎初始化结果 + 两个本机 sidecar 的实时状态。
  - `argos=Ready` / `madlad=Ready`：对应本机翻译服务已就绪；
  - `Failed`：启动或健康检查失败，常见原因是未下载模型、未配置启动命令或服务未在运行（见 §1 与 [hardware-requirements.md](hardware-requirements.md#4-配置入口环境变量)）；
  - `Stopped`：尚未启动 / 已停止（后台探测完成前会短暂显示）。
  - 若显示「引擎初始化失败：…」，翻译功能不可用，需先排查（DLL 缺失或被杀软 / Smart App Control 拦截是常见原因，见 [terminology.md](terminology.md) 的 SAC 条目）。
- **路由决策行**：显示最近一次翻译的**结果来源、引擎名与耗时**，标签含义见 §3 第 4 步。

### 2.2 翻译主界面

| 控件 | 说明 |
|---|---|
| 输入（Source） | 多行输入框，支持换行；内容为空时点「翻译」只会清空输出，不发请求 |
| 源语言 | `自动检测` + 11 种常用语言：中文 / English / 日本語 / 한국어 / Français / Deutsch / Español / Русский / Português / Italiano / العربية |
| ⇄ 交换 | 交换源 / 目标语言；源语言为「自动检测」时不可用（悬停有提示） |
| 目标语言 | 同上 11 种语言（无「自动检测」选项） |
| 模式 | `实时档（Realtime）`（默认）与 `精译档（Full）`，见 §4 |
| 隐私模式（强制离线） | 勾选后禁止一切联网升级，见 §5 |
| 翻译 | 发起翻译；进行中此按钮禁用 |
| 取消 | 放弃本次翻译。**引擎调用无法中断，结果会被丢弃**（按钮悬停即此说明） |
| 存入 TM | 把当前「输入 + 译文」作为用户确认的记忆对写入 TM，见 §6.2 |

### 2.3 输出与状态

- **输出（Target）**：只读，绿色文本；失败时显示 `[错误码] 错误说明`（如 `[NO_RESULT] …`）。
- **状态消息**（绿色）：TM / 术语表操作与翻译取消等反馈，例如「已存入 TM」「TM 共 12 条（en→zh）」「翻译已取消」。
- **提示行**（灰色）：原文为——「TM 与术语表按上方所选语言对查看；『标坏』的 TM 记录不再命中。离线翻译需要该语言对已安装本地模型（当前 en↔zh 走 Argos/CT2…）；未安装的语对会显式回落，上方标签显示「兜底降级」。」

## 3. 一次文本翻译的完整流程

1. 在输入框填写文本，选择源 / 目标语言（或让源语言「自动检测」）。
2. 选择模式；敏感内容请勾选「隐私模式」。
3. 点「翻译」。引擎按路由优先级链处理（模式与升级规则见 §4）；界面显示细进度条，窗口不卡（调用在工作线程执行）。
4. 读输出与路由标签：
   - `[TM 命中]` → 直接复用了历史译文（含置信度/质量分）；
   - `[本地引擎]` → 本地模型直接产出；
   - `[AI 精译]` → 升级到了 Ollama LLM，结果已写入 TM；
   - `[兜底降级]` → 未能按预期路径完成，回落到了其它本地引擎（例如 demo），**引擎会在消息里说明原因，不会静默降级**。
5. 需要固化这条译文时，点「存入 TM」。

### 3.1 超时、重试与取消

- 单次引擎调用逐次超时默认 **45 秒**（可用环境变量 `WONSLATE_UI_TRANSLATE_TIMEOUT_MS` / 旧拼写 `LT_UI_TRANSLATE_TIMEOUT_MS` 覆盖，取正整数毫秒）。这个默认值是个**兜底上限**而非首防线：它刻意高于 Rust 引擎自身等待 `429 busy` 退避的最坏耗时（`busy_retry 12s + 单次超时 30s = 42s`），以免界面在引擎正在正确等待时先撒手。
- **超时后不再自动重试**（旧版会重试 1 次）。原因：引擎调用不可中断，重试会叠一个全新解码在未中止的后台解码之上，反而拖慢服务（已量过的并发放大）。超时时输出区直接提示「翻译超时（45s）…可重试，或改用实时档 / 无需联网的本地模型」，由你手动决定。
- **多行/长文本粘贴**：sidecar 逐行串行翻译、整份只占一个名额，耗时≈各行之和；页面量级（百词上）可能达 ~25 s 以上。若常超 45 s，要么分段粘贴，要么走实时档（argos）或换更小模型。
- 「取消」是**逻辑取消**：底层调用仍在后台跑完，但结果会被丢弃、不会覆盖界面。适合 Ollama 响应太慢时及时止损。

### 3.2「自动检测」的实际能力

当前为 MVP 启发式：**文本中含任意 CJK 汉字 → 判定为中文，否则判定为英文**。也就是说它只能区分 zh / en 两类；其它语言请手动选择源语言。翻译成功后引擎会回报真实源语言代码，供 TM / 术语表的写入使用（所以源语言为「自动检测」时，需先成功翻译一次才能管理 TM 与术语表）。

### 3.3 语言对未安装模型时会发生什么

界面不会假装成功：路由会把该请求交给下一可用引擎，并在消息中说明回落原因，路由标签显示 `[兜底降级]`。最终可能落到：
- `madlad`（已下载时——它对 450+ 语言码任意互译）；
- `demo` 词表（`i love the world` 这类"词级替换"输出即来自它）；
- 全部失败 → 输出 `[NO_RESULT]`，提示为该语言对安装本地模型或启用 AI 引擎。

## 4. 两种模式（档位）

| | 实时档（Realtime） | 精译档（Full） |
|---|---|---|
| 默认本地引擎 | `argos`（en↔zh 实时） | `madlad`（11 种语言任意互译） |
| AI 升级 | **从不升级**（延迟预算优先） | 默认「只要 Ollama 可达就升级」 |
| 典型延迟 | 句级 <0.1 s | madlad 0.7–2 s；升级到 LLM 再 +2–8 s |
| 适用 | 对话、语音链路 | 文本精译、质量优先场景 |

- 精译档的 AI 升级默认策略是 `always`（这就是"精译"的含义）；把设置改为「省成本优先」后变为 `low_confidence`（仅在本地结果低于 0.85 阈值时才升级），见 §8。
- 若 Ollama 不可达，精译档**不会**空等超时：引擎先探测可达性，不可达就本地出结果，并在消息中标注「AI upgrade engine 'ollama' is not reachable; served locally instead」。
- 界面语言下拉为 11 种常用语言；其它语言代码可通过 SDK 使用（见 [sdk.md](sdk.md)），覆盖范围取决于引擎：`madlad` 450+ 语言码，`argos` 仅 en↔zh，`ollama` 取决于所拉取的模型。

## 5. 隐私模式

勾选后该请求 `privacy=true`，引擎执行**不可旁路**的本地化约束：

- 禁止 AI 升级（即便在精译档、即便 Ollama 可用）；
- 若显式指定了非本地引擎，会被强制钳制为本地 `demo` 并在消息中说明「privacy mode: non-local engine '…' clamped to local 'demo'」；
- 本地结果置信度偏低（<0.70）时提示「privacy mode: low confidence, AI upgrade prevented」，但结果照常返回。

产品层面：Wonslate 没有云后端，翻译文本不出设备；本机 sidecar 服务只绑定 `127.0.0.1`。

## 6. TM 记忆库（页签一）

TM = Translation Memory（翻译记忆库）。核心价值：**AI 精译一次 → 入 TM → 相同内容后续零成本复用**。列表显示当前所选语言对的活跃条目，按命中次数从高到低。

| 列 / 按钮 | 说明 |
|---|---|
| 源文 / 译文 / 引擎 / 命中 | 条目内容、产出引擎、被复用次数 |
| 刷新 | 重新读取当前语言对的条目（每次切到本页签也会自动刷新） |
| 标坏所选（不再命中） | **软删除**：该条不再被命中、也不再出现在列表，但记录仍保留在磁盘上可查 |

### 6.1 自动写入规则（无需干预）

- AI 精译结果：`quality = 0.95`，写入后异步触发蒸馏（见 §7 术语表）；
- 本地引擎结果：按置信度估算，**≥ 0.70** 才写入（低于此值不污染记忆库）；
- 命中时 `hit_count` 自增，用于排序与蒸馏优先级。

### 6.2「存入 TM」按钮（人工确认）

把当前输入框 + 输出框的内容写为一条记忆对：`engine=manual`、`quality=1.0`（人工确认最高可信）。使用前注意：

- 输入与输出都必须非空（先翻译一次）；
- 源语言为「自动检测」时必须先成功翻译一次（否则提示「请先翻译一次再存入 TM」）。

### 6.3 缓存质量下限（进阶）

精译档有一个「缓存质量下限」（默认 0.0 = 任何缓存都直接复用）。设为 0.95（即「质量优先」偏好）后，低于该质量的缓存会被**重新翻译**而不是复用；若此时 AI 不可达、重翻也只能得到同样结果，引擎会照常返回缓存并在消息里说明「quality preference not honoured: …」——这是有意为之的"不静默降级"。

## 7. 术语表（页签四）

术语表用于把**固定译法**注入翻译上下文，保证同一术语在整篇、整个领域内一致。注入的是**本句确实出现的术语**（按术语是否为原文子串判定），默认最多 20 条，上限由配置项 `glossary_max_terms` 控制；若一句都没命中，则不注入任何术语（不拿无关术语凑数）。

- **手工维护**：填写「原文 → 译文」后点「新增/更新」；删除用「删除所选」；「刷新」重读。手工条目的来源为 `manual`、置信度 1.0。
  - **同一个术语改第二次，改得动了**（旧版会静默保留第一次的译法而照样提示"已保存"，缺陷 D49）。
  - **保存即锁定**：经界面保存的行会带上锁定标记——蒸馏与术语包之后都不能再改它；你自己的编辑始终可以（锁定是挡机器的，不是锁住你自己的）。
- **锁定 / 解锁所选**：锁定=这条译法由我定；解锁=允许蒸馏与术语包再次更新。状态取自引擎的回读，不是界面自己假设的。
- **自动蒸馏**：AI 精译结果会异步抽取术语（过滤阈值 0.80），来源为 `distill`；已锁定的行不受其影响。
- **列**：原文 / 译文 / 置信度 / 来源（`manual` / `distill` / `tm` / `seed:<领域>`）/ 锁定 / 频次。机器抽取的条目尤其值得复核。
- **带领域的行也能删了**：术语的主键含领域段，所以选中一条 `seed:av` 之类的行点「删除所选」，删的就是那一行，不会碰到同名的通用行（旧版删不到领域行，而有同名通用行时还会删错那一行——缺陷 D50）。删不到对应行时界面会说「未删除：库里已找不到…」而不是假装成功。
- 与 TM 一样，源语言为「自动检测」时需先成功翻译一次。

## 8. 设置（页签二）：质量与成本

精译档的行为由「质量与成本」偏好决定（二选一）：

| 选项 | 效果 | 界面原文说明 |
|---|---|---|
| 省成本优先 | 升级策略改为"本地低于阈值才升级"；缓存一律直接复用 | 「本地引擎能翻就用本地，命中缓存直接用。最快、最省；缓存的译文可能来自本地引擎（质量 0.88）。」 |
| 质量优先 | 每次都交给 AI 精译；并拒绝复用低于 AI 质量（0.95）的缓存 | 「每次都交给 AI 引擎精译，且不直接使用本地引擎写入的缓存（会重新精译一次，此后使用 AI 结果）。更慢、更贵。注意：没有可用的 AI 引擎时缓存会整体失效，同一句话每次都要重新翻译。」 |

关键操作规则：

- **保存后需重启软件生效**——引擎在启动时读取配置，界面用红字明示，避免"改了没生效"的错觉；
- 「重新读取」刷新下方信息；「当前实际生效的配置（由引擎返回）」区显示真实生效值（精译档升级策略 / 缓存质量下限、实时档本地引擎、用户设置文件路径）；
- 若未保存过任何偏好，会明确提示「当前使用部署默认值——它既不是上面两项」；
- 若检测到**环境变量正在覆盖用户设置**，会逐名列出（排查"为什么设置没起作用"的第一现场）。

配置优先级（低 → 高）：内置默认 < `routes.json`（部署默认） < `settings.json`（用户选择） < 环境变量 < `tt_init` 参数。完整清单见 [hardware-requirements.md](hardware-requirements.md#4-配置入口环境变量)。

## 9. 语音（离线）（页签三）

现在提供**两条输入链路**：**麦克风录音**与 WAV 文件。两者走同一条 `VAD 分段 → SenseVoice 识别 → 引擎翻译 → Kokoro 合成 → 播放` 链路。麦克风采集会先**对齐到模型要求的 16 kHz 单声道**（设备给其它采样率时自动转换）；这一步是硬的——不转换就会被 VAD 拒绝，所以不会静默把非 16k 的声音送下去。

**前置条件**：语音模型（VAD + ASR + TTS）就绪。缺模型时页签顶部会直接列出缺哪些，并提示获取方式：

```bash
python script/fetch_voice_models.py --only all
# 或用环境变量指向已有模型目录：
#   LT_VOICE_MODEL_DIR / ASR_MODEL_DIR / TTS_MODEL_DIR
```

**操作步骤**：

1. **麦克风**：点「开始录音」，说完点「停止并翻译」——输入设备用 Windows 默认麦克风；录音有 **60 秒上限**，到顶会自动截断并在说明区写明丢了多少采样（不会假装录全了）；
2. 或 **WAV**：点「选择 WAV…」（16 kHz 单声道效果最佳），再点「识别并翻译」；
3. 源 / 目标语言、模式、隐私开关**沿用主界面**的选择（主界面源语言为「自动检测」时，语音路径按中文处理）；
4. 查看「识别文本（ASR）」与「译文」；
5. 「播放译文」——把合成的目标语言语音写入临时文件后用系统播放器播放；
6. 耗时行显示 `VAD …ms · ASR …ms · 翻译 …ms · TTS …ms · 首段可播 …ms · 合计 …ms`。

失败与降级（如某段没有产出语音、麦克风被占用或不存在）会写入状态行与说明区，不会让程序崩溃。

### 9.1 真机验收（M4，约 5 分钟；需本机有麦克风与语音模型）

双击仓根的 `voice_acceptance.bat`（或 `python script/voice_acceptance.py`）。脚本会启动应用并逐项问你看到什么：是否已就绪、录音状态是否变化、ASR 是否是你的话、译文是否正确、能否听到译文语音、耗时行是否完整。

**它不会替你判定——“空回车 / 跳过”一律算“没验证”，不是通过；只有每一项都明确答 `y` 才退出码 0。** 结果写成 `docs/evidence/voice-m4-acceptance-<UTC>.json`（内含应用与引擎 dll 的 sha256、UTC 时间、每项问题与你的回答；不写盘符）。若语音页签顶部提示缺模型，先跑 `python script/fetch_voice_models.py --only all` 再验。

脚本里**不重复一份模型路径规则**：缺不缺模型由应用自己报（两套规则会各自漂移）。

## 10. 数据存放位置与隐私

默认数据目录：Windows `%LOCALAPPDATA%\Wonslate`（可用 `WONSLATE_DATA_DIR` 覆盖，旧拼写 `LT_DATA_DIR` 优先）。

```
<数据目录>/
├─ data/
│  ├─ translator_tm.json    # TM 记忆库（当前实现为 JSON 文件；设计文档中的 SQLite 方案未采用）
│  └─ glossary.json         # 术语表
├─ config/
│  ├─ settings.json         # 用户在设置页保存的质量/成本偏好
│  └─ routes.json           # 部署方可选的默认路由表（不存在则用内置默认）
└─ models/                  # Argos / MADLAD / 语音模型（不进仓库）
```

- **备份 / 迁移**：整体拷贝数据目录即可。
- **清空记忆库**：关闭应用后删除 `data/translator_tm.json` 与 `data/glossary.json`。
- **隐私**：翻译文本只在本机流转。sidecar 服务只绑定 `127.0.0.1`，默认地址也是它；**勾选隐私模式后**，即
  使有人把 `WONSLATE_ARGOS_URL` / `WONSLATE_MADLAD_URL` 配到了别的机器，本次请求也不会把文本发
  出去——该引擎会被钳制回内置词典引擎作答，并在结果里点名被拒的地址；连本机 Ollama 也不会被
  调用。需要注意隐私模式**不关闭本机落盘**（TM 与术语表仍写硬盘）。完整判据、留存清单与不适用的
  入口见 [privacy-architecture.md](privacy-architecture.md)。

## 11. 常见问题（FAQ）

| 现象 | 原因与处理 |
|---|---|
| 输出像"逐词替换"（如 `i love 这个 世界`） | 落到 `demo` 词表引擎：该语言对没有本地模型。按 §1 下载模型，标签将变为 `[本地引擎]` |
| 标签总是 `[兜底降级]` | 期望的引擎不可用（模型缺失 / sidecar 未运行）。看顶部诊断行与输出消息里的回落原因 |
| 精译档没有升级到 AI | Ollama 未运行或模型未拉取；消息会写「'ollama' is not reachable; served locally instead」 |
| 输出 `[NO_RESULT]` | 没有任何引擎能处理该语言对：装对应模型（如 madlad）或启用 Ollama |
| 老是超时 | 单次逐次超时默认 45 s（`WONSLATE_UI_TRANSLATE_TIMEOUT_MS` 可调）；Ollama 大模型 / 无 GPU、或多行长粘贴（逐行串行≈各行之和）都可能超过。改用实时档、换更小模型（`WONSLATE_OLLAMA_MODEL`）、或分段粘贴 |
| 顶部显示「引擎初始化失败」 | `translator_engine.dll` 缺失，或被安全策略（Smart App Control / 杀软）拦截本地构建产物；换官方发布包或在合规环境处理 |
| TM 页签提示「源语言为自动检测，请先翻译一次」 | 这是正常约束：自动检测需一次成功翻译才能确定语言代码 |
| 语音页签提示缺少模型 | 运行 `python script/fetch_voice_models.py --only all`，或用 `ASR_MODEL_DIR` 等变量指向已有目录 |
| 改了设置没生效 | 设置**重启后生效**；若下方「实际生效」列出了环境变量，它优先于你在界面上的选择 |
